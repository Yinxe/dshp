# package.json 逐字段规范

> 本文承接旧 AGENT.md §3（package.json 规范）的完整细节。规则版总纲见[仓库根 AGENT.md](../AGENT.md)。

以 `plugins/vision-bridge/package.json` 为模板，只改值不改结构：

| 字段                   | 规范                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| ---------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `name`                 | `@dshp/<目录名>`。发包前确认 scope 可用（见 docs/release-and-compat.md）。                                                                                                                                                                                                                                                                                                                                                                 |
| `version`              | 新插件 `0.1.0` 起；遵循 semver，breaking 才升 major。                                                                                                                                                                                                                                                                                                                                                                                      |
| `type`                 | 必须是 `"module"`。                                                                                                                                                                                                                                                                                                                                                                                                                        |
| `main`                 | `"./lib/host.js"`（DSH 加载后端 bundle 的入口）。                                                                                                                                                                                                                                                                                                                                                                                          |
| `exports`              | 三项固定：`"."` → `./lib/host.js`，`"./client"` → `./lib/client.js`，`"./package.json"` → `./package.json`。                                                                                                                                                                                                                                                                                                                               |
| `files`                | `["lib", "cordis.patch.yml", "README.md"]`，不多不少。LICENSE 全仓只在仓库根保留一份（MIT），不进子包也不进 `files`。                                                                                                                                                                                                                                                                                                                      |
| `engines`              | `"node": ">=20"`。                                                                                                                                                                                                                                                                                                                                                                                                                         |
| `scripts`              | 六件套照抄：`dev: tsup --watch` / `build: tsup` / `typecheck: tsc --noEmit` / `clean: rm -rf lib *.tsbuildinfo` / `test: node --check lib/host.js && node --check lib/client.js && echo "syntax ok"` / `prepublishOnly: pnpm typecheck && pnpm build`，外加 `lint: oxlint --deny-warnings --config ../../.oxlintrc.json src tsup.config.ts`。test 有真实逻辑时可追加（见下表），但 `node --check` 两行不许删（lib 提交完整性的最后防线）。 |
| `dependencies`         | **永远 `{}`**。运行时零依赖是架构红线，见 docs/build-and-deps.md。                                                                                                                                                                                                                                                                                                                                                                         |
| `devDependencies`      | 只放构建/类型：`tsup`、`@deepseek-ai/schemastery`（用 settings 才要）；**有 client 再加三件套** `react` + `@types/react` + `@deepseek-ai/dsh-client-ui-primitives`。react 类型锁 `~18.3.1`（跟随运行时内置的 React **18.3.1**），SDK 包**锁死与运行时同号**（如 `0.1.5-rc.1`，不写 `^`——`^0.1.5-rc.1` 会解析到 rc.2）。其余版本用 `^` 跟随标杆。                                                                                           |
| `repository.directory` | 维护中的插件写 `plugins/<name>`，归档插件写 `archive/<name>`；别忘改（clone 出来的模板指向旧目录是常见 bug）。                                                                                                                                                                                                                                                                                                                             |
| `publishConfig`        | `{ "access": "public", "provenance": true }` 照抄（Trusted Publishing 用）。                                                                                                                                                                                                                                                                                                                                                               |
| `dsh.bundle.patch`     | `"./cordis.patch.yml"`；`dsh.client.platform` 为 `"web"`（有 client 才保留整个 `dsh` 块，纯 host 插件删掉 `dsh.client`）。                                                                                                                                                                                                                                                                                                                 |

## `test` 脚本的现有追加项

| 插件               | 追加                                                                                           |
| ------------------ | ---------------------------------------------------------------------------------------------- |
| file-change-viewer | `node scripts/check-host.mjs && node scripts/check-patch.mjs && node scripts/check-client.mjs` |
| mcp-manager        | `node scripts/patchdoc.test.mjs`                                                               |
| token-meter        | `node scripts/check-share-tokens.mjs`（分享卡导出 token 覆盖自检）                             |
| web-style          | `node scripts/check-themes.mjs`（目录 ↔ 画廊 meta ↔ 产物一致性）                               |

新增自检脚本时：放 `scripts/*.mjs`、只许用 node 内建模块、进 `pnpm test`、失败必须非零退出。

## 唯一例外：mcp-manager 的 `yaml`

mcp-manager 需要解析/回写 `cordis.patch.yml`，`devDependencies` 里多了 `yaml`（构建时经 `noExternal` 内联进 `lib/host.js`，运行时仍零依赖）。其他插件没有等价需求时不得效仿。
